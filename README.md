## 📌 프로젝트 소개

**SWITCH**는 소규모 카페 및 음식점의 근무 일정과  
대체근무 요청을 간편하게 관리하기 위한 서비스입니다.

복잡하게 흩어져 있던 근무 일정과 대체근무 과정을 한곳에서 관리하여  
관리자와 근무자 모두의 일정 관리를 돕습니다.

### 📅 프로젝트 기간

**2026.09.14 ~ 2026.10.01**

## ✨ 주요 기능

### 관리자

- 사업장 생성 및 근무자 관리
- 정기 근무 패턴 등록
- 주간 근무 스케줄 생성 및 관리
- 대체 근무 요청 승인
- 대체 근무 승인 시 근무자 자동 변경

### 근무자

- 개인 근무 일정 조회
- 근무 불가능 시간 등록
- 대체 근무 요청
- 대체 근무 요청 조회 및 수락

### 공통

- 회원 인증 및 권한 관리
- 대체 근무 요청 상태 관리
- 알림 기능

## 🤝 Convention

### Branch

```text
feat/기능명
```

예시

```text
feat/admin-login
feat/schedule-create
fix/substitute-request
```

### Commit

| Type | 설명 |
| --- | --- |
| `feat` | 새로운 기능 추가 |
| `fix` | 버그 수정 |
| `test` | 테스트 코드 추가 및 수정 |
| `docs` | 문서 추가 및 수정 |
| `refactor` | 비즈니스 로직 변경 없이 코드 구조 개선 |
| `chore` | 설정, 의존성 등 기타 작업 |

### Code Style

- Google Java Style Guide 기반
- Java 들여쓰기 Space 4칸
- IntelliJ Project Code Style 공유
